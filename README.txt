UniLink Smart Living — website prototype
========================================
Files:
- index.html: Arabic RTL landing page and appointment request form
- styles.css: responsive design using a palette inspired by the visible UniLink logo (blue, black/navy, white)
- script.js: interactive smart-home scenes, needs questionnaire, and demo booking form

Important before publishing:
1. Replace the illustrative CSS artwork with approved UniLink project photography and the official logo file.
2. Connect the appointment form to a backend/database or booking service and configure staff notifications.
3. Set actual office opening hours, available appointment slots, address, phone and privacy terms.
4. The form currently stores demo requests only in the visitor's browser localStorage; it does NOT send requests to UniLink.
5. Appointment requests are explicitly pending confirmation by the UniLink team, not auto-confirmed.
6. Review all product/service claims for accuracy before launch.

Open index.html in a browser to preview. An internet connection is needed for the Google Font; a fallback font is included.
